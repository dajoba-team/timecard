# 바뀐 것 (버전별)

1~15는 claude.ai 아티팩트로 만들고 올렸어요 (1~11: 2026-11-11, 12~15: 2026-11-12~13). 16부터는 Supabase + Netlify 판이에요.

> 번호 정리 (2026-11-13): Supabase 판을 처음엔 12·13으로 적었는데, 그사이 아티팩트에서 12~15가 따로 올라가서 Supabase 판을 16~18로 다시 매겼어요.
