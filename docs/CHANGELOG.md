# 바뀐 것 (버전별)

1~11은 2026-11-11에 claude.ai 아티팩트로 만들고 올렸어요.

| 버전 | 내용 |
|---|---|
| 1~2 | 출퇴근 화면(태블릿), 사장님 화면, 일·월·년 기록, 근무 집계, 실시간 인건비, 월급대장(인쇄·CSV), 지각 의심 알림, 예시 데이터 |
| 3 | 휴대폰 메일 알림 켜기/끄기 (Gmail), 시험 메일, 마지막 발송 결과 표시 |
| 4 | 사진 인증 켜기/끄기 (시각·이름 새김, 사진 없음/확인 필요 표시, 메일에 사진 첨부, 저장 공간 확인·오래된 사진 지우기) |
| 5 | 정기 휴무 표시 (근무 집계·달력·직원 목록), 휴무일 근무 표시 |
| 6 | 요일별 근무날/휴무날 버튼 |
| 7 | 근무날을 다시 고르면 시간 칸이 나오지 않던 문제 수정 |
| 8 | 사장님 마스터 번호 (대리 입력 표시), 직원 번호가 관리·마스터 번호와 겹치지 않게 막기 |
| 9 | 전자 근로계약서 (첫 출근 때 자동 작성, 손가락 서명, 사장님 서명 등록·자동 서명, 변경 계약서, 인쇄·메일 사본), 숨긴 회색 덮개가 화면을 가릴 수 있던 문제 수정 |
| 10 | 세무사 전달용 급여 내역 (문자 양식, 문자용 복사·메일·매월 1일 자동), 월급제 직원, 주민등록번호(선택) |
| 11 | 전체 백업(.json), 출퇴근 기록 전체 엑셀(.csv), 마지막 백업 표시 |
| 12 (2026-11-12, 배포 전) | claude.ai 아티팩트 → Supabase + Netlify로 이전 준비: `public/storage.js`(로그인, docs 테이블, 실시간 반영, 사진 photos 버킷, 파일 저장), `supabase/schema.sql`. 메일 기능은 잠시 꺼 둠 (준비 중 안내). 데이터 이전 스크립트(`scripts/import.mjs`), 계정 패널·로그아웃, 인터넷 끊김 시 전송 대기 목록, 날짜에 묶인 시험 2개 고침 (시계 고정) |
| 13 (2026-11-12, 배포 전) | 슬랙 미출근 알림: 서버(Supabase Edge Function + 5분 예약 작업)가 확인해서 슬랙으로 보냄, 직원·날짜당 1번, 현황 화면에 켜기/끄기·시험 알림·마지막 결과 |
| 13-1 (2026-11-12, 배포 전) | Supabase를 장부와 같은 프로젝트로 변경: 모든 자원에 `tc` 접두어(`tc_docs`, `tc_audit_log`, `tc-photos`, `tc-notyet-check`, `TC_` secret), 타임카드 권한(`app_metadata.apps`) 있는 계정만 접근, 권한 없으면 안내 화면 |
